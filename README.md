# Real Time Weather App

A responsive weather application built using HTML, CSS, JavaScript and OpenWeatherMap API as part of my internship project.

## Features
- Search weather by city name
- Displays Temperature, Humidity, Wind Speed, and Feels Like
- Uses real-time data from OpenWeatherMap API
- Clean and responsive UI

## Technologies Used
- HTML5
- CSS3 
- JavaScript
- OpenWeatherMap API

## How to Run
1. Clone this repository
2. Get your API key from openweathermap.org
3. Paste the API key in `index.html` file
4. Open `index.html` in any browser
